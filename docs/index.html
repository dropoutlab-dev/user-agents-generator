02 · Capabilities

✦ Features

Everything a scraping, testing, or automation pipeline needs — nothing it doesn't.

📦

Zero dependencies

No transitive supply chain. No postinstall. Nothing to audit beyond the source you can read.

🛡️

Header‑injection safe

headers() rejects CR, LF, control characters, empty strings, and anything over 512 chars.

🌐

Traffic‑weighted

Chrome appears as often as it does in the wild. Opera does not appear as often as Chrome.

🚀

Loaded once

The dataset is resolved at require‑time, not per call. No repeated I/O inside your hot loop.

🧪

Tested on CI

node:test + GitHub Actions matrix on Node 20, 22, and 24. Audit runs on every push.

🅣

Types shipped

.d.ts included. No @types/ package to install, no any leakage.

🔁

Single instance

index.mjs re‑exports index.cjs. CJS and ESM consumers share one dataset copy.

🍂

Fails safe

If the dataset cannot resolve, frozen 2025 templates take over. The return value is never "".

03 · Examples

⌨ Usage

Four entry points for the same module. Pick the one that fits your runtime, expand it, and copy the snippet.

index.js 
const ua = require('user-agents-generator');

console.log(ua.chrome());
console.log(ua.firefox());
console.log(ua.safari());
console.log(ua.android());
console.log(ua.ios());
console.log(ua.random());
index.mjs 
import { random, generate, headers } from 'user-agents-generator';

const ua = random();
console.log(ua);

const chromeMac = generate({ browser: 'chrome', os: 'macos' });
const h = headers(ua);
scrape.js 
const puppeteer = require('puppeteer');
const { chrome } = require('user-agents-generator');

(async () => {
  const browser = await puppeteer.launch({
    headless: true,
    args: [`--user-agent=${chrome()}`]
  });
  const page = await browser.newPage();
  await page.goto('https://example.com', { waitUntil: 'domcontentloaded' });
  await browser.close();
})();
fetch.js 
const { headers } = require('user-agents-generator');

await fetch('https://example.com/api', {
  headers: {
    ...headers(),
    'Accept': 'application/json'
  }
});
03 · API

ƒ Legacy methods

Unchanged names and signatures from v1. Upgrading does not require code changes.

Method Returns
chrome() Chrome on desktop
firefox() Firefox on desktop
safari() Safari on Apple platforms only — never Chromium-family
android() Chrome on Android
ios() Safari on iOS
03.1 · API

+ Added in v2

Method Returns
edge() Microsoft Edge on desktop
opera() Opera on desktop
random() Any family, weighted by the dataset
generate(options?) A UA matching the given constraints
headers(ua?) Object containing User-Agent and companion headers
03.2 · API

⚙ generate(options)

All fields optional. Constraints are regex-escaped before matching, so arbitrary strings are safe.

Option Type Description
browser string Family name or literal substring — chrome, firefox, safari, edge, opera, android, ios
os string windows, macos, linux, android, ios, or any literal substring
device string desktop, mobile, or tablet
✓
Safe by design. generate({ browser: 'chrome(' }) does not throw. A constraint that matches nothing falls back to an unconstrained draw. Non-object input throws TypeError.
03.3 · API

▤ headers(ua?)

Returns a ready-to-send header object. Validates the UA it is given.

Behaviour Detail
Valid input Returns { 'User-Agent', 'Accept', 'Accept-Language', 'Accept-Encoding' }
Invalid input Throws TypeError on CR, LF, control chars, empty strings, or > 512 characters
Why reject? Silently stripping a CRLF would hide a header-injection attempt
05 · Upgrade

⇄ Migration from v1

v1 was unmaintained for roughly three years. v2 keeps the legacy method surface intact and adds typed output, ESM support, and client-hint headers.

Aspect v1 v2
Install npm i user-agents npm i user-agents-generator
Import (CJS) require('user-agents') require('user-agents-generator')
Import (ESM) — import { chrome } from 'user-agents-generator'
TypeScript None index.d.ts shipped
Headers helper — headers(ua?) for client-hints
Constrained generation — generate(options)
Dataset update Manual Synced daily; fallback baked in

Migration checklist

  • Replace the user-agents dependency with user-agents-generator.
  • Update every require / import path.
  • Legacy calls (chrome(), firefox(), safari(), android(), ios(), random()) work unchanged.
  • Adopt headers() in fetch calls if you currently set User-Agent manually — you'll get consistent client hints for free.
  • Node ≥ 20 is required.
